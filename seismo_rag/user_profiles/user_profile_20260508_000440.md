# SAGE User Profile

## Inferred identity and work context
- 推测为地球物理、地震学或相关领域的研究人员或工程师，可能从事天然地震或人工源数据分析工作。
- 日常工作涉及绘图（地形图、波形图）和信号处理，具备处理实际观测数据的能力。

## Research/software interests
- **核心工具**：GMT（通用制图工具）用于绘制地形图；波形处理工具（如 waveform_io、b_value_analysis）用于正弦波生成、噪声添加、重采样、震相拾取。
- **研究方向**：地震波形分析、信号处理、地震定位或震相识别，可能涉及三分量地震数据处理。

## Habits and preferences
- **交互风格**：分步提出需求，从简单到复杂（先画净波形，再加噪声，再调整采样率，最后拾取震相），表明喜欢渐进式验证。
- **数据使用**：倾向于复用已有数据（如将单分量波形复制为三分量），而非从头创建复杂合成数据。
- **输出偏好**：直接获得图形结果（PNG格式），不要求理论解释，更注重功能执行成功。

## Knowledge level
- **专业水平**：中级至高级。了解GMT指令、采样率概念、震相拾取、三分量数据含义，能直接提出专业操作（如“拾取震相”）。
- **工具熟悉度**：对绘图和波形处理工具的操作命令非常熟悉，不依赖助手解释步骤。

## Intent and routing hints
- **常见意图**：① 数据可视化（地形/波形图）；② 信号预处理（加噪、重采样）；③ 模拟或真实数据上的震相检测与提取。
- **路由偏好**：优先路由到擅长 **GMT 绘图**、**地震波形处理**（含噪声添加、重采样、震相拾取）的技能模块。若涉及三分量数据，需支持通道扩展或合并。

## Open uncertainties
- 是否处理真实地震数据（对话中使用了合成正弦波）？未来可能转向实际数据，需支持多种格式（如 SAC、MSEED）。
- 是否需要自动化批处理（如批量绘图、批量拾取）？当前仅单次操作，但可预留批量处理接口。
- 对绘图质量（分辨率、色彩、标注）是否有特定要求？未提及，但可以根据后续需求调整。
