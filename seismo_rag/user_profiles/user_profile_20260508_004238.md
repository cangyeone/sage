# SAGE User Profile

## Inferred identity and work context
- 推测为地球物理学、地震学或相关领域的科研人员/研究生，涉及信号处理与地震波形分析。
- 工作内容涵盖波形可视化与简单处理（添加噪声、调整采样率）、震相拾取、地形图绘制等。
- 可能处于研究或教学场景，反复测试不同工具（GMT、Obspy）的成图能力。

## Research/software interests
- **核心工具**：GMT（用于绘制地形图）、ObsPy（用于地震学数据处理与绘图）、波形IO相关技能。
- **研究兴趣**：三维介质中的波动方程（标量与弹性波）、信号噪声处理、波形合成（如sin波）、三分量数据构建。
- **可能领域**：地震层析成像、震源机制、波传播模拟或地震监测。

## Habits and preferences
- 倾向直接给出操作指令（如“绘制一下波形”），而非详细描述需求。
- 习惯逐步扩展任务：从简单波形到添加噪声，再到调整采样率、合成三分量、并应用震相拾取。
- 喜欢测试不同工具完成同一任务（如“用GMT绘制” vs “用obspy绘制”），可能探索工具差异或验证系统能力。
- 对话中包含“测试1”、“测试2”等短句，表明可能处于系统调试或学习阶段。

## Knowledge level
- **高等水平**：理解三维波动方程（标量/弹性）、P波/S波分解、拉梅常数等概念，具备波动理论基础知识。
- 熟悉数值采样率（100Hz）、频率（100Hz）、方差（0.1）等参数，说明具备信号处理基础。
- 能使用多个专业软件/库，表明有实操经验。

## Intent and routing hints
- **常见意图**：
  - 波形生成与可视化（优先路由到 `waveform_io` 技能）。
  - 噪声/信号处理（`b_value_analysis` 或自定义噪声添加技能）。
  - 地形图绘制（`gmt_plotting` 技能）。
  - 震相拾取（可能需要 `phase_picker` 或 AI 辅助）。
- **路由偏好**：当提到“绘制”、“波形”时，优先调用波形处理技能；提到“GMT”、“obspy”时，分别调用对应绘图技能。
- **理论提问**：如“什么是三维介质方程”，应返回数学表达式与物理含义，保持公式清晰、分类明确。

## Open uncertainties
- 用户是否在同一项目中工作？多个对话可能来自不同会话，但使用相同工具（GMT、ObsPy）暗示统一领域。
- 用户对GMT/Obspy的熟练程度：从请求“绘制全国地形图”看，可能更熟悉GMT，但也会尝试Obspy。
- 系统测试意图：多次要求“测试1”、“测试2”可能为验证系统响应，非真实研究需求。
- 震相拾取时提及“复制三份当成三分量”，是否期望自动合成？后续可能需要提供三分量处理流程。
