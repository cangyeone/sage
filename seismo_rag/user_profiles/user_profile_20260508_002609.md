# SAGE User Profile

- 工作场景：涉及波动理论、波形数据处理、地震学绘图及分析。

## Research/software interests
- 主要研究方向：地震波传播、波动方程、信号处理（含噪声、采样率）、震相识别。
- 常用软件/工具：GMT（地理/地形绘图）、ObsPy（地震数据处理与波形分析）、可能涉及数值计算库（如波形生成与噪声添加）。

## Habits and preferences
- 偏好直接执行并输出可视化结果（如地形图、波形图），而非纯理论解释。

- 常通过操作步骤逐步细化需求（先画基础波形，再叠加噪声，再调整坐标，最后进行震相分析）。

## Knowledge level
- 高级水平：理解三维波动方程（标量及弹性矢量形式），熟悉P波、S波、拉梅常数、波速关系等概念。
- 实践技能：能熟练使用专业工具（GMT/ObsPy）进行数据处理与可视化，了解震相拾取与三分量数据的概念。

## Intent and routing hints
- 常见意图：
  - 获取/验证物理公式或波动方程形式。
  - 请求定制化的地球科学绘图（如地形图）。
  - 数据生成、处理、可视化（如含噪声波形、调整采样率）。
  - 执行地震学专业分析（如震相拾取、三分量处理）。
- 路由偏好：
  - 优先调用地学/地震学相关技能：`gmt_plotting`、`waveform_io`、`b_value_analysis`、`tabular_io` 等。
  - 对代码或命令较少解释，更期望直接输出结果。
