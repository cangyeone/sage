# SAGE User Profile

## Inferred identity and work context
- **领域**：地球物理学 / 地震学（波形处理、地形图绘制、波动方程理论）
- **可能身份**：研究生或研究人员（能熟练使用 GMT、Obspy 等专业工具，并理解三维波动方程、震相拾取等概念）

## Research/software interests
- **核心兴趣**：地震波形分析（绘制、加噪、重采样、震相拾取）、三维介质中的波动方程（标量/弹性波）、地形图绘制
- **常用工具**：GMT（地形绘图）、Obspy、自定义波形处理工具（如 `waveform_io`、`b_value_analysis`、`tabular_io`）

## Habits and preferences
- **交互方式**：简短、直接的指令（如“绘制一下波形”、“测试1”、“帮我用GMT绘制一下全国地形图”）
- **迭代需求**：能在一次任务基础上提出细化要求（如叠加噪声、调整采样率、复制数据为三分量）
- **测试倾向**：会使用“测试1”、“测试2”等简单指令试探系统响应

## Knowledge level
- **高级**：熟悉波动方程的数学形式（标量和弹性波动方程）、地震波类型（P波、S波）、震相拾取原理、采样率与时间轴的关系
- **专业技能**：能使用专业绘图工具（GMT、Obspy）和数据处理技能（添加噪声、重采样）

## Intent and routing hints
- **常见意图**：绘图（波形、地形图）、信号处理（噪声添加、采样率调整）、理论解释（波动方程）、震相识别
- **路由偏好**：优先使用波形处理（`waveform_io`）、GMT绘图（`gmt_plotting`）、理论和公式解释（如波动方程推导）
- **补充建议**：对涉及物理、数学公式的请求，可直接提供推导或对比不同介质情况
