# SAGE User Profile

## Inferred identity and work context
- 地球物理学/地震学领域的研究者或工程师
- 可能从事地震波传播、波形处理、地形制图等相关工作
- 涉及固体地球物理或勘探地球物理方向

## Research/software interests
- 波动方程理论（特别是三维介质中的标量和弹性波动方程）
- 地震波形数据生成、分析与处理（sin波、噪声、采样率、震相拾取）
- 绘图工具：GMT（通用制图工具）、Obspy（地震学Python库）
- 地形制图（全国地形图）

## Habits and preferences
- 倾向于直接给出具体问题，逐步细化需求（例如从绘制sin波形到添加噪声、设置采样率、拾取震相）
- 交互中会尝试不同工具完成类似任务（如先要求GMT绘制地形图，又要求Obspy绘制）
- 对命令式、可执行技能（如GMT、Obspy、波形生成）有较高依赖

## Knowledge level
- 专业水平：掌握波动方程数学形式，理解P波/S波、标量/矢量波、拉梅常数等概念
- 工具熟练度：熟悉GMT基本操作（下载地形数据、生成图像），了解Obspy基本功能
- 波形处理：了解采样率、噪声方差、震相拾取等信号处理概念

## Intent and routing hints
- 常见意图：获取理论公式、生成/处理波形数据、制图输出
- 路由偏好：应优先调用地球物理/地震学相关技能（如gmt_plotting, waveform_io, b_value_analysis, tabular_io），提供数学公式时用LaTeX详细展开
- 回答深度：偏好专业、精确、带参数细节的回答（如方程完整形式、工具输出路径和文件大小）
