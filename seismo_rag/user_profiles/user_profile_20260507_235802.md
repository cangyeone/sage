# SAGE User Profile

## Inferred identity and work context
- **Likely domain**: Geophysics / Seismology (震相拾取、三分量数据是地震学常见术语) 或信号处理相关研究或教学。
- **Role**: 研究生、科研人员、工程师或课堂实验用户，需要借助工具完成快速波形生成与处理。

## Research/software interests
- **核心兴趣**: 信号生成与处理（正弦波、噪声添加、采样率调节）、地震学中的震相拾取、三分量数据格式。
- **工具偏好**: 依赖自动化脚本或仿真环境（如 Python/Matlab），期望系统提供直接可用的图形输出（png）和数值结果。

## Habits and preferences
- **交互模式**: 逐步迭代式请求——先基础绘图，然后添加噪声，再调整坐标，最后提出更专业的处理（震相拾取、三分量复制）。
- **输出偏好**: 期待图形化结果（图像文件），对数值细节（点数量、采样时长）也有明确关注。
- **语言简洁**: 指令直接、无额外解释，偏好一次完成一个子任务。

## Knowledge level
- **基础概念**: 熟悉正弦波、高斯噪声、方差、采样率、时间-振幅坐标轴。
- **专业概念**: 了解“震相拾取”（P/S波到时识别）、“三分量数据”的含义，能提出合理简化（复制波形代替真实三分量），表明具备地震学或信号分析基础知识。

## Intent and routing hints
- **常见意图**: 快速验证算法/工具功能、准备教学演示素材、测试波形处理流程。
- **路由偏好**:
  - 优先路由到 **波形生成/处理** 技能（如 `waveform_io`, `b_value_analysis`, `tabular_io`）。
  - 若有地震学专用技能（如震相自动拾取、三分量工具），应优先调用。
  - 避免冗长解释，直接执行并返回结果。

## Open uncertainties
- 是否真实用于地震数据（而非模拟）？后续可能提出加载真实数据。
- 震相拾取的具体要求（人工/自动？P/S波识别？）未明确，需进一步澄清。
- 是否需输出三分量分离的单独文件或仅示意？当前复制三份的逻辑可接受，但未来可能要求不同分量有独立噪声或偏移。
