面向地球物理专家的合作介绍

SAGE：把地震学常用数据处理流程变成可复现、可审查、可协作的研究助手

SAGE 不是要替代地球物理学家的判断，而是希望把波形读取、震相拾取、事件目录、知识检索、代码执行和结果记录连接成一套透明的科研工作流，让专家能更快检查假设、复现实验并沉淀方法规范。

合作切入点 当前原型能力

为什么需要地球物理专家参与

过去几年，震相拾取、事件关联、地震定位、背景噪声成像和台阵分析等工具不断成熟，但实际研究中仍常见三类问题：流程分散、参数选择依赖经验、结果质量难以系统追踪。SAGE 的目标是把这些“隐性经验”转化为可执行、可复查的工作流。

对非 AI 方向的地球物理专家来说，SAGE 的价值不在于“模型有多新”，而在于它能否遵守地震学逻辑、保留中间证据、暴露不确定性，并让专家能及时纠正错误。

合作的核心问题：如何让智能体不仅会运行工具，而且知道哪些结果在地球物理上不可信。

建议合作对象画像

固体地球物理 地震波成像 台阵方法 地球物理反演

以姚华建教授这类地震学与成像专家为例，公开资料显示其研究涵盖地震波成像、背景噪声层析成像、地壳浅层及岩石圈结构、大地震破裂过程、台阵方法与地球物理反演。这类研究方向非常适合为 SAGE 提供真实问题、质量标准和 benchmark case。

当前原型已经具备的能力

自然语言到可执行代码

用户可以用中文描述任务，例如读取 SAC、绘制波形、做震相拾取或生成结果表。系统会生成代码、运行、保留 stdout、图件和下载文件。

地震学技能库

已接入 waveform I/O、可视化、PNSN 震相拾取、事件关联、地形/地图绘制等技能说明，减少模型临时编造 API 或命令的风险。

知识库与 Web Search

支持上传文献、构建本地知识库，并在 Config 中统一配置 arXiv、OpenAlex、Brave 等搜索源，服务 Chat 与 Geo Agent。

可复现实验记录

每次 smoke workflow 会输出 run id、目录、CSV、图件和报告，避免后续对话丢失上下文或重新生成错误数据。

质量防线

新增了震相拾取 guard：禁止把 STA/LTA 的第一个触发直接当成震相，避免把记录开头的滤波/taper 假触发误标为 P/S 到时。

专家可审查

系统强调中间产物、候选触发、参数、图件和日志。专家可以检查每一步，而不是只看到一个黑箱答案。

SAGE 的工作流视角

1

问题定义

用自然语言描述区域、数据、科学问题与期望输出。

2

资料读取

读取 SAC/MSEED/CSV/PDF，记录数据路径、采样率、台站与时间范围。

3

工具执行

调用 ObsPy、PNSN、绘图、检索、地理工具或用户已有脚本。

4

结果检查

检查空结果、假触发、缺文件、不可读图像和参数不合理。

5

产物沉淀

保存目录、图件、表格、报告和可复现 run record。

建议与姚华建老师讨论的合作切入点

1. 真实 benchmark case

选择一个小而完整的地震学案例，例如一段连续波形的震相拾取与事件目录构建、一个台阵波形处理任务，或一个背景噪声资料处理流程。

2. 专家质量标准

定义什么叫“可信结果”：到时误差、事件数量、S-P 合理性、台站覆盖、图件检查项、参数范围和失败条件。

3. 可复现教学与科研模板

把常见研究流程整理成可复用模板，让学生先理解科学逻辑，再逐步深入每个工具和参数。

第一次会议建议目标： 不讨论“大模型能不能替代科学家”，只请老师帮助判断一个具体原型是否值得继续做：选一个代表性地球物理流程，明确输入数据、期望产物和专家验收标准。

可以直接发给老师的简短说明

姚老师您好，我们最近在尝试开发一个面向地震学研究流程的开源原型系统 SAGE / SeismicX。它不是单个 AI 拾取器或聊天机器人，而是希望把波形读取、震相拾取、事件目录、文献知识库、代码执行、图件和中间结果记录连接起来，形成一套可复现、可审查的地震学工作流助手。

我们特别希望请地球物理专家参与，是因为这类系统真正困难的地方不只是“会调用工具”，而是要知道哪些结果在地震学上不可信。例如近期我们就发现，简单 STA/LTA 容易把记录开头的滤波假触发误判为震相，因此系统需要专家定义质量标准、失败条件和 benchmark case。

如果您方便，我们想请您从地震波成像、台阵地震学、背景噪声或地震目录构建等方向，帮我们选择一个小而完整的真实流程，看看 SAGE 是否能把数据、代码、参数、图件和结果检查完整记录下来。我们希望先做一个能被专家审查的原型，而不是做一个不可解释的“AI 自动科研”演示。

当前限制与诚实边界

SAGE 目前仍是研究原型：底层结果依赖数据质量、台站覆盖、工具配置和专家约束。它不能保证自动得出正确地球物理解释，也不应替代人工审稿式检查。当前最合适的定位是“把流程跑通、把证据留下、把错误暴露出来”。
